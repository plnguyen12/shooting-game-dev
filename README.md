[NƠI CHỨA FILE SB3]
Là một tựa game "bắn súng" 2D, góc nhìn thứ 3, được tạo bằng Scratch (về sau là TurboWarp) từ 2023. Vẫn đang trong quá trình phát triển. Các bạn có thể đóng góp để project được phát triền thêm.
HƯỚNG DẪN SỬ DỤNG:
Mỗi build sẽ có các bản: sb3, Windows, Linux, HTML (x86-64)
Tải về và thử nghiệm theo ý muốn.
LƯU Ý: File SB3 chỉ mở trong TurboWarp; vị trí các biến số chắc chắn sẽ sai, vui lòng điều chỉnh vị trí các biến (tham khảo build gần đây nhất). Ngoài ra có biến "time sb" cần phải điều chỉnh, hiện biến này lên, hiện sprite "TIME TO SUPER BOSS SPAWN" và căn chỉnh cho phù hợp,
